Markdown to Flow

Turns Markdown user flows with Mermaid diagrams into editable flow diagrams and documentation cards, natively in Figma and FigJam. Upload or paste your flow, pick your options, and generate a structured, editable result on the canvas.

How to use this plugin

  1. (Optional) Download the example markdown to see the expected format.
  2. Upload a .md / .markdown / .txt file, or paste your user flow content into the text area.
  3. Go to the Customize Flow tab to choose what to generate (diagram, documentation cards), the layout style, direction, and language.
  4. Back on the Upload tab, press Generate.
  5. Your flow diagram and documentation appear on the canvas as native, editable elements.

Tip: an exact file structure isn't required — the plugin detects sections and the Mermaid diagram wherever it finds them, and does its best with what's there.

Resources used

  • Figma Plugin API — typings and canvas APIs (built with esbuild; no other runtime dependencies)
  • Mermaid flowchart syntax — the diagram source format the plugin parses (with its own parser, no runtime dependency)
  • Figma UI3 — design tokens, text styles and icons used by the plugin panel
