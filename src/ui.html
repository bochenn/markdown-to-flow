Markdown to Flow

Turns Markdown user flows with Mermaid diagrams into editable flow diagrams and documentation cards, natively in Figma and FigJam. Upload or paste your flow, pick your options, and generate a structured, editable result on the canvas.

Resources used

  • FigUI3 — native-style UI components for the plugin panel
  • Mermaid flowchart syntax — the diagram source format the plugin parses (with its own parser, no runtime dependency)
  • Figma Plugin API — typings and canvas APIs (built with esbuild; no other runtime dependencies)
